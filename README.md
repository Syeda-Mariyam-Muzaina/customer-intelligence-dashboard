Customer Intelligence Dashboard

An AI-powered Customer Intelligence System that performs:
- Customer Segmentation (K-Means Clustering)
- Spending Prediction (Logistic Regression)
- Business Recommendations
- Interactive Dashboard using Streamlit

---

Features

- Customer Segmentation using K-Means  
- Spending Behavior Prediction  
- Real-time User Input Prediction  
- Business Recommendation Engine  
- Interactive Dashboard UI  
- Data Visualization using Plotly  

---

 Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Plotly

---

 Machine Learning Models

 K-Means Clustering
- Used to group customers based on:
  - Annual Income
  - Spending Score
- Helps identify customer segments

 Logistic Regression
- Predicts whether a customer is:
  - High Spender 💰
  - Low Spender 🛍️

---

Dashboard Features

- Customer segmentation visualization
- Real-time prediction using sliders
- Business recommendations
- Confusion matrix & model performance
